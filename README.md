## SELECTED SECURITY & INFRASTRUCTURE WORK

### Security Operations Dashboard

Developing a Linux-based security and operations platform designed to centralize visibility across systems managed by Summit.

**Focus areas:**
- Infrastructure and endpoint health
- Security status and operational visibility
- Linux-based data collection
- Automated status reporting
- Centralized monitoring
- Web-based operations interface

The project is being designed so monitoring logic and data sources can support multiple interfaces without duplicating the underlying collection architecture.

---

### Network Operations Center Display

Built a dedicated Raspberry Pi/Linux NOC system providing persistent, at-a-glance monitoring of production infrastructure.

**Implemented capabilities include:**
- Automated infrastructure reachability monitoring
- Internet performance collection
- Network and server status
- Production-system visibility
- External service monitoring
- Scheduled Linux collectors
- JSON-backed dashboard data
- Chromium kiosk deployment
- Secure remote administration

The system provides a lightweight operational view without requiring administrators to continuously open individual management platforms.

---

### Cloud Backup & Disaster Recovery

Designed and implemented a layered backup strategy for managed Windows endpoints and servers using **MSP360 and Amazon S3**.

**Areas of implementation include:**
- Endpoint and server backup policies
- File and image-based backup strategies
- AWS S3 storage
- Retention policies
- Protected backup storage
- Backup monitoring
- Restore testing and validation
- Recovery planning

The objective is not simply successful backup jobs, but having a documented and tested path to recovering business-critical systems and data.

---

- ISP/network migration support
- Configuration backup and recovery planning
