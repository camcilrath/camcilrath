## 🔒 Featured Projects

### 🧩 [Pi-hole DNS Filtering Lab](https://github.com/ChrisMcIlrath/pihole-dns-filtering-lab)
Deployed Pi-hole on a Raspberry Pi to block ads, malicious domains, and telemetry network-wide.  
- Configured recursive DNS and privacy-focused settings  
- Implemented custom blocklists and tested filtering effectiveness  
- Documented setup, troubleshooting, and performance results  

---

### 💻 [Ubuntu Server Home Lab](https://github.com/ChrisMcIlrath/ubuntu-server-homelab)
Repurposed a Dell Latitude laptop as an Ubuntu Server to host cybersecurity tools and experiments.  
- Managed users, permissions, and static IP configuration  
- Installed Docker and SSH key authentication for remote administration  
- Acts as the base infrastructure for all security projects  

---

### 🧠 [Wazuh SIEM Deployment](https://github.com/ChrisMcIlrath/wazuh-siem-homelab)
Built a full SIEM stack to collect, analyze, and respond to endpoint and network events.  
- Deployed Wazuh All-in-One on Ubuntu Server  
- Enrolled Windows and macOS agents for centralized logging  
- Created detection scenarios for brute-force and privilege escalation events  
- Documented analysis and alert triage processes  

---

### 🔐 [SSH Hardening Guide](https://github.com/ChrisMcIlrath/ssh-hardening)
Focused on improving remote access security and reducing attack surface.  
- Disabled password authentication and root login  
- Configured key-based authentication and least privilege access  
- Demonstrated secure administration best practices
